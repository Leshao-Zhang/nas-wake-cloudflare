# ESP8266 唤醒中继

家里常开的板子。每隔 8 秒问一次你的 Worker 域名，看到待开机就向局域网广播地址 `:9` 发魔术包，再回报已消费。

域名、MAC、广播地址、Wi-Fi 和设备令牌只放在本地的 `secrets.h`，不出现在网页上，也不进仓库。

## 准备

- Arduino IDE 2 + ESP8266 板卡包（本机板载 USB 坏时用 Uno 转接，见下）
- 或 [PlatformIO](https://platformio.org/)（USB 正常的板子可直接 `pio run -t upload`）
- 板子要连到与 NAS 同一子网的 Wi-Fi。路由器不要开 AP 隔离
- Cloudflare 里已经设好 `DEVICE_TOKEN`

## 写入密钥

Arduino 工程：

```bash
# 复制并编辑 esp8266/NasWake/secrets.h
cp NasWake/secrets.h.example NasWake/secrets.h
```

PlatformIO 工程：

```bash
cd esp8266
cp include/secrets.h.example include/secrets.h
```

填家里 Wi-Fi、与 Worker 相同的设备令牌，以及 `WAKE_HOST`、NAS MAC、广播地址。`secrets.h` 已被忽略，不要提交。

## 编译与烧录（本项目实机）

当前这块 NodeMCU **板载 USB 不可用**（端口重置失败），已用 **Arduino Uno 转接烧通**。完整踩坑与步骤：

→ **[`用Arduino烧录.md`](用Arduino烧录.md)**

要点摘要：断 CH340→RX；Uno RESET 接地后 **TX–TX / RX–RX**；IDE 选 **NodeMCU 1.0**，烧录时 D3 接地；工程打开 `NasWake/NasWake.ino`。

USB 正常的板子仍可用：

```bash
cd esp8266
pio run -t upload
pio device monitor
```

串口（115200）应出现 `WiFi 已连接`、`时间已同步`，然后每隔约 8 秒 `poll 空闲`。偶发 `poll HTTP -1` 后恢复属 ESP8266 HTTPS 抖动。

若看到 `poll 令牌不对`，核对 `DEVICE_TOKEN`。若长期 TLS 失败，先确认 NTP，再更新 `certs.h` / `NasWake/certs.h`。

## 联调

1. 手机打开你的自定义域名，输入开机密码，按开机，页面显示「待开机」。
2. 一轮轮询内应出现 `要开机` → `魔术包已发出` → `已回报消费`（接串口时可见）。
3. 页面变为「指令已消费」。
4. NAS 打开网络唤醒且网口待机灯亮时，关机/睡眠应能被唤醒。

本机与 NAS 同网段时，可用抓包确认魔术包：ESP → 广播地址:9，UDP length 102。充电器单独供电、不插电脑时同样有效。

## 证书

固件用 BearSSL 校验 `WAKE_HOST`。信任锚在 `include/certs.h`（与 `NasWake/certs.h` 保持一致）：

- GlobalSign ECC Root CA - R4
- GTS Root R4

需要正确时间，故先 NTP。两轮之间不深睡。

```powershell
$hostName = "wake.example.com"   # 换成你的 WAKE_HOST
$tcp = New-Object System.Net.Sockets.TcpClient($hostName, 443)
$ssl = New-Object System.Net.Security.SslStream($tcp.GetStream(), $false, ({ $true }))
$ssl.AuthenticateAsClient($hostName)
$chain = New-Object System.Security.Cryptography.X509Certificates.X509Chain
$chain.Build($ssl.RemoteCertificate) | Out-Null
$chain.ChainElements | ForEach-Object { $_.Certificate.Subject }
$ssl.Close(); $tcp.Close()
```
