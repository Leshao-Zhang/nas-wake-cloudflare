# 用 Arduino Uno 给 NodeMCU 烧录

本文沉淀自本项目实机排查（板载 USB「端口重置失败」、FaryLink 出厂固件、CH340 占 RX、最终烧通并抓到魔术包）。

适用场景：**NodeMCU 板载 Micro-USB 无法枚举 / 一直重置失败**，但 ESP8266 本身还能跑（例如能开热点）。用 **Arduino Uno 当 USB 转串口** 烧录。

---

## 0. 先分清两件事


| 现象        | 含义                            |
| --------- | ----------------------------- |
| 电脑只有 COM1 | **板载 USB↔CH340 硬件链路坏了**，换驱动没用 |
| 能搜到WiFi   | ESP 有电、MCU 还能跑，只是 USB 烧录口坏了   |


板载 CH340 即使 USB 坏了，上电后仍可能 **驱动着 ESP 的 RX**。这时 Uno 能读到启动日志（ESP→电脑），但烧录超时（电脑→ESP 被 CH340 抢走）。

---

## 1. 硬件：必须先断开 CH340→ESP RX

切断 CH340 到 RX 的走线

断口之后：板载 Micro-USB **不要再当数据口**；供电用 **3.3V** 或独立 USB 充电器。

## 2. 接线（Uno RESET 接 GND 时：同名相接）

Uno 的 **RESET 必须短接 GND**，让 ATmega 停住，只留板上 USB 串口芯片。

此时丝印 TX/RX 是「单片机视角」，对外部设备要 **同名相接**，**不要**按常见的 TX↔RX 交叉：


| Uno              | NodeMCU    |
| ---------------- | ---------- |
| **TX(1)**        | **TX**（直连） |
| **RX(0)** → 分压 → | **RX**     |
| GND              | GND        |
| 5V               | VIN        |




### 5V→3.3V 分压（Uno RX→NodeMCU RX）

手头若无 1k/2k，可用：

```text
Uno RX(0) ──[560]──[560]──●──── NodeMCU RX
                           │
                         [2.2k]
                           │
                          GND
```

约 `5V × 2.2/(1.12+2.2) ≈ 3.3V`。  
**禁止** Uno TX/RX 5V 直连 NodeMCU RX。

色环备忘：560≈绿蓝棕金；2.2k≈红红红金。

### 接线图

```text
                    Arduino UNO                              NodeMCU
                 ┌──────────────┐                        ┌──────────────┐
     USB ───────►│  USB 串口芯片 │                        │              │
                 │              │                        │              │
        ┌─短接──►│ RESET    GND │◄──共地─────────────────│ GND          │
        │        │              │                        │              │
        └────────│──────────────│                        │              │
                 │          5V  │──────VIN──────────────►│ VIN          │
                 │              │                        │              │
                 │        RX(0) │──[560]──[560]──●──────►│ RX           │
                 │              │               │        │              │
                 │              │             [2.2k]     │              │
                 │              │               │        │              │
                 │              │              GND       │              │
                 │              │                        │              │
                 │        TX(1) │◄───────────────────────│ TX           │
                 │              │                        │              │
                 │          GND │◄──烧录时短接───────────│ D3 (GPIO0)   │
                 └──────────────┘                        └──────────────┘
```

烧录时：**拔掉 NodeMCU 的 Micro-USB 数据线**（若还插着电脑）；只靠 VIN 供电。

## 3. 串口自检（烧之前必做）

1. Uno 插电脑，记下真实端口（例如 **COM3/COM4**，不是主板 COM1）。
2. 监视器波特率 **74880**，按 NodeMCU **RST**。
3. 应看到类似：

```text
ets Jan  8 2013,rst cause:2, boot mode:(1,6)
```


| boot mode 第一位 | 含义               |
| ------------- | ---------------- |
| **(1,x)**     | 下载模式（GPIO0 接地正确） |
| **(3,x)**     | 正常从 Flash 启动     |


- 完全没字、且曾交叉接线 → 改成 **TX–TX / RX–RX** 再试。  
- 有字但仍是很老的 `SDK ver: 2.0.0 ... 2016` → 还是出厂固件，说明**还没烧进**我们的程序。

Uno 的 RX 灯闪一下、监视器却没字：多半是交叉接错或波特率不对；打开监视器本身也可能闪 RX 灯，不能单凭灯判断。

---



## 4. Arduino IDE 设置（NodeMCU）



### 4.1 添加 ESP8266 开发板支持（首次）

1. 打开 Arduino IDE。
2. **文件 → 首选项**（macOS 为 **Arduino IDE → Settings…**）。
3. 找到 **其他开发板管理器地址** / **Additional boards manager URLs**，填入：

```text
http://arduino.esp8266.com/stable/package_esp8266com_index.json
```

若已有其他地址，用英文逗号分隔追加即可。

1. 确定后打开 **工具 → 开发板 → 开发板管理器**。
2. 搜索 **esp8266**，安装 **esp8266 by ESP8266 Community**（本项目用过 3.1.2）。
3. 装完后 **工具 → 开发板 → ESP8266 Boards** 里应能看到 NodeMCU。



### 4.2 烧录时选用的板型

直接用 **NodeMCU 1.0** 即可，不必改成 Generic 通用板：


| 项            | 值                                |
| ------------ | -------------------------------- |
| 开发板          | **NodeMCU 1.0 (ESP-12E Module)** |
| Upload Speed | **115200**                       |
| 端口           | Uno 的 COMx                       |


烧录时仍须 **D3 接地**（手动进下载模式）。Uno 转接没有 DTR/RTS 自动复位，所以要点上传前后靠 D3 + RST 配合；板型本身选 NodeMCU 1.0 没问题。

---



## 5. 烧录步骤

1. 打开 `项目`。
2. **关掉串口监视器**（占端口会导致上传失败）。
3. **D3（GPIO0）接 GND**（或按住 FLASH）。
4. 按一下 RST，确认曾能进 `boot mode:(1,6)`。
5. 点上传。出现 `Connecting...` 若仍慢，再按一下 RST（D3 保持接地）。
6. 等到 **Writing at … 100%** / Done uploading。
7. **断开 D3**，按 RST。
8. 监视器改 **115200**，应看到：

```text
正常的日志输出
```

---



## 6. 常见报错对照


| 现象                                    | 处理                                                                 |
| ------------------------------------- | ------------------------------------------------------------------ |
| `Timed out waiting for packet header` | 查：D3 是否接地；是否 TX–TX/RX–RX；CH340→RX 是否已切断；监视器是否已关；Connecting 时再按 RST |
| 监视器 74880 没字                          | 同名相接、共地、VIN 供电、Uno RESET↔GND                                       |
| `constexpr IPAddress` 编译失败            | 用 `const IPAddress`（已改工程）                                          |
| 仍显示 SDK 2.0.0 (2016)                  | 上传未成功，不要当已烧入                                                       |


---

## 7. 知识要点（给以后的自己 / Agent）

1. **板载 USB 重置失败 ≠ ESP 坏了**；先看能否出热点/串口日志。
2. **Uno 作转接且 RESET 接地 → TX–TX、RX–RX**，不是交叉。
3. **NodeMCU 上 CH340 会占 RX**；能读不能烧时优先断 CH340→RX（本板为 `221`）。
4. IDE 直接选 **NodeMCU 1.0**；烧录靠 **D3 接地 + RST** 进下载模式。
5. 下载模式看 **74880 / boot mode:(1,x)**；业务日志看 **115200**。
