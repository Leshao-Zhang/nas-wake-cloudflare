# 部署 NAS 唤醒服务

代码在这个目录。Worker 提供开机页面和四个接口，状态放在一个 SQLite Durable Object 里。网页不包含 MAC 和 IP。

## 准备

- Node.js 20 或更新版本
- 一个 Cloudflare 账号。免费计划即可，要用 SQLite Durable Object

```bash
cd worker
cp wrangler.jsonc.example wrangler.jsonc
npm install
npx wrangler login
```

## 自定义域名

部分网络会污染 `workers.dev` 的 DNS，浏览器和 ESP 请用你自己的域名。编辑本地的 `wrangler.jsonc`（已从 example 复制，且被 gitignore），把 `routes[0].pattern` 改成你的域名（须在同一 Cloudflare 账号下）。`wrangler.jsonc` 不要提交。

## 设置密钥

两把密钥都只放在 Cloudflare，不写进仓库。开机密码自己定。设备令牌用一长串随机字符，给以后的 ESP8266 用：

```bash
openssl rand -base64 24
npx wrangler secret put WAKE_PASSWORD
npx wrangler secret put DEVICE_TOKEN
```

每条命令会提示输入。输入时不回显。已经部署过之后再执行，会覆盖旧值。

## 部署

```bash
npx wrangler deploy
```

命令结束时会打印 `https://nas-wake.<账号>.workers.dev`。这个地址可作备份，但建议网页和 ESP 都走上面的自定义域名。

第一次部署会按 `wrangler.jsonc` 里的 `v1` 创建 Durable Object。以后不要改这个 `tag`，也不要把它从 `migrations` 里删掉。

## 页面

1. 密码框为空时，「开机」不能按。
2. 密码错误时，页面显示「密码错误」，状态不变。
3. 密码正确后显示「待开机」。页面每 2 秒查一次。
4. 设备回报成功后显示「指令已消费」。
5. 两分钟内没有成功回报，显示「未送达」。待开机期间再按一次，这两分钟重新计时。

用命令看接口（把域名换成你的）：

```bash
BASE=https://wake.example.com

curl -s -X POST "$BASE/api/wake" \
  -H 'content-type: application/json' \
  -d '{"password":"错误密码"}'

curl -s -X POST "$BASE/api/wake" \
  -H 'content-type: application/json' \
  -d '{"password":"开机密码"}'

curl -s -X POST "$BASE/api/status" \
  -H 'content-type: application/json' \
  -d '{"password":"开机密码"}'
```

正确开机后，`/api/status` 先返回 `{"status":"pending"}`。无人回报时，超过 2 分钟再查，变为 `{"status":"expired"}`。

## 设备接口

ESP8266 使用另一把密钥，不能用开机密码。

轮询不改变状态：

```bash
curl -s "$BASE/api/poll" -H "authorization: Bearer 设备令牌"
```

待开机且未过期时返回 `{"wake":true}`，否则 `{"wake":false}`。令牌不对时也是 `{"wake":false}`，HTTP 状态为 401。

发出魔术包之后再回报：

```bash
curl -s -X POST "$BASE/api/ack" -H "authorization: Bearer 设备令牌"
```

当前是待开机时改为已消费，返回 `{"ok":true}`。已经是已消费时再回报，仍返回 `{"ok":true}`，状态不变。空闲或已过期返回 `{"ok":false}`。

回报没送到时，状态保持待开机。下一轮轮询仍是 `{"wake":true}`，可以再发一次魔术包。

## 本地预览

把 `.dev.vars.example` 复制为 `.dev.vars`，填入两把密钥，然后：

```bash
npx wrangler dev
```

`.dev.vars` 已被忽略，不要提交。本地预览的地址只在这台电脑上，到不了家里的局域网。
